# NeoRun — الحارس الذكي للتدريب الرياضي

تطبيق ويب يتتبّع حركتك بالكاميرا عبر نموذج **MoveNet**، ويعدّ التكرارات ويصحّح الوضعية لحظياً. التحليل كله يتم داخل المتصفح.

## المزايا
- **3 تمارين**: سكوات، ضغط، رفع الذراعين جانباً، مع عدّ تلقائي واكتشاف التكرار الناقص والوضعية الخاطئة.
- **تنبيهات صوتية بالعربي**، عدّ تنازلي، مؤقّت، وهدف تكرارات.
- **تسجيل مقاطع اختياري** (حد أقصى 3 دقائق) يُحفظ مشفّراً في IndexedDB.
- **حسابات محلية**: كلمة المرور تُشتق بـ PBKDF2 (210,000 تكرار)، والبيانات تُشفّر بـ AES-256-GCM.
- **سجل الجلسات** مع إحصائيات، نسبة الوضعية الصحيحة، وتصدير CSV.
- ملف شخصي مع مؤشر كتلة الجسم وهدف يومي.
- تصميم متجاوب للجوال، ووضع داكن تلقائي.

## التشغيل
الكاميرا والتشفير يحتاجان `https` أو `localhost`:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو انشره على **GitHub Pages** (Settings → Pages → Branch: main).

## الهيكل
| الملف | الوظيفة |
|---|---|
| `js/common.js` | الحسابات، التشفير، التخزين، الهيدر والتنقل |
| `js/exercises.js` | منطق التمارين وعدّاد التكرارات (بدون واجهة) |
| `js/camera.js` | الكاميرا، النموذج، الرسم، التسجيل |
| `tests/exercises.test.js` | اختبار منطق العدّ: `node tests/exercises.test.js` |
